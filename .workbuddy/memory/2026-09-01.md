- **横向滚动条踩坑（已解决）**：DataGrid 要出底部横向滚动条必须满足两点——① 所有列都用固定宽度，任何一列用 `Width="*"` 都会吃掉剩余空间使内容永不溢出；② `HorizontalScrollBarVisibility="Visible"`（`Auto` 在窗口够宽时不显示）。现列宽合计 850px（编号80/姓名120/性别60/年龄60/电话130/时间150/状态80/操作170），800px 主窗口下必然出现滚动条。
- `ViewModel/CustomerViewModel.cs`：操作列命令为 `EnableCommand`（Status 置 0，恢复启用）+ `DeleteCommand`（Status 置 1，逻辑删除）；另提供 `SaveRow(CustomerInfo)` 供自动入库调用。用户已把 `Query()` 改名 `GetCustomers()` 并删掉 ResetCommand。
- **单元格改完自动入库**：DataGrid 加 `CellEditEnding="CustomerDataGrid_CellEditEnding"`，code-behind 里先 `textBox.GetBindingExpression(TextBox.TextProperty)?.UpdateSource()` 把值强制刷回实体（CellEditEnding 触发时源对象往往还是旧值），再调 VM 的 `SaveRow`。`e.EditAction != DataGridEditAction.Commit`（Esc 取消）时跳过。项目没装 Microsoft.Xaml.Behaviors.Wpf，所以用 code-behind 事件而不是 Interaction Trigger。

## 客户列表分页（仿用户给的参考 XAML）

- **装了 Microsoft.Xaml.Behaviors.Wpf 1.1.31（离线）**：从 `~/.nuget/packages/microsoft.xaml.behaviors.wpf/1.1.31/lib/net45/` 复制到 `packages/Microsoft.Xaml.Behaviors.Wpf.1.1.31/lib/net45/`，csproj 加 Reference（PublicKeyToken=b03f5f7f11d50a3a），packages.config 登记。这样 XAML 里才能用 `xmlns:i="http://schemas.microsoft.com/xaml/behaviors"` 的 `Interaction.Triggers`。
- **新建 `usercontrols/ucPage.xaml(.cs)`**：依赖属性 `TotalPage` / `PageIndex` / `TotalCount`（均 `BindsTwoWayByDefault`），路由事件 `PageChanged`（冒泡，`RoutedPropertyChangedEventHandler<int>`，携带新旧页码）。UI 为 首页/上一页/下一页/末页/跳页 + 共 N 条 + 第 X/Y 页，边界自动禁用按钮。csproj 里需手动加 Page + Compile 两项。
- **Interaction 传参坑**：`InvokeCommandAction` 不写 `CommandParameter` 时会把事件参数传给命令；而 `CommandParameter="{Binding ..., ElementName=xxx}"` 在 `Interaction.Triggers` 集合里 ElementName 可能解析不到（这些对象不在可视化树/命名范围里）。所以命令参数留空，VM 里同时兼容 `int` 和 `RoutedPropertyChangedEventArgs<int>` 两种入参。
- `CustomerViewModel`：新增 `PageIndex/PageSize/TotalCount/TotalPage` + `PageChangedCommand`；`GetCustomers()` 改用 `repository.GetListByPage(exp, PageIndex, PageSize, ref total)` 并计算总页数，**注意接口里分页方法已被用户改名为 `GetListByPage`**（不是 `GetList` 重载）。删除末页最后一条导致页码越界时回退到最后一页重查。`QueryCommand` 会把 PageIndex 重置为 1。
