- `Models/CustomerInfo.cs`：顺手修了和 `UserInfo` 一样的 `Password` 字段错用 bug。
- 跳转主窗口改为在 `LoginViewModel` 内完成：成功后 `new MainWindow().Show()` 再 `window.DialogResult = true` 关闭登录窗；`App.xaml.cs` 只保留登录失败/取消时 `Shutdown()`，避免弹出两个 MainWindow。注意顺序——必须先 Show 主窗口再关登录窗，否则应用会直接退出。
